# 金匮 1.0 设计重做笔记（hark/redesign-2026-10）

> 依据：0.9.0（1bf5e2d）CI 截图逐张审阅 + 同类应用调研。只借鉴交互与版式思路，没有参考或复制任何 GPL 应用的代码。

## 一、现状问题（0.9.0 截图）

### 视觉
1. **没有一个主色**：墨黑按钮 + 赤金点缀 + 暖纸底，三种“主色”互相抢；赤金在浅底上发灰发棕，统计环形图被一大块土黄占满，整体显旧。
2. **描边过多**：列表每一行、筛选标签、分段控件、按钮、底部面板、搜索都有 1dp 描边，满屏细线，层次反而不清楚。
3. **卡包首页头重脚轻**：一张置顶卡面（约 250dp 高）压在首屏，真正的列表只露出两三行；“最近使用”磁贴又和下面的行重复。
4. **顶栏右上的描边胶囊**（三个图标装进一个白色胶囊）像一个按钮而不是三个，视觉重量过大。
5. **字体层次**：页面标题用宋体字标“金匮 / 账本”，和其余黑体界面不搭；分组标题“全部 5”的数字小胶囊与内容抢眼。
6. **记一笔面板**：分类是带描边的小方块（64dp），选中态是橙色描边 + 浅底，像表单；金额被挤在面板中下部，不是视觉焦点；数字键全部带描边。
7. 深色模式整体偏暖褐，与卡面的冷色（靛蓝、深绿）不协调。

### 交互
1. **悬浮按钮挡内容**：卡包的“新建”盖住第三行的复制按钮；账本的“记一笔”盖住金额（截图里 ¥3,800.00 被挡住一半）。
2. **主操作不在拇指区**：账本的搜索 / 统计 / 锁定都在右上角；切换卡包与账本的底栏只有两个标签，中间空着。
3. **记账步数**：打开账本 → 点“记一笔” → 选分类 → 输金额 → 完成；没有“常用分类一点即记”，默认账户只是“上一笔的账户”，午饭和房租用的往往不是同一个账户，要再点一次改。
4. **列表行没有手势**：卡片想置顶要长按 → 面板 → 置顶；想复制账号（不是行尾那个密码）要进详情；流水想删除要点开 → 删除 → 确认。
5. **看验证码要进详情**：两步验证码只在详情页显示，想复制 GitHub 的验证码要 搜索 / 找 → 进详情 → 复制。
6. **详情页**：每一行都带“眼睛 + 复制”两个图标，复制最常用的账号 / 密码要先在一列图标里找到对的那个；删除按钮放在顶栏，误触成本高。
7. **账本没有日历视图**，补账、对账只能一路往下翻。
8. 设置、账户、预算、周期、锁屏没有截图测试，改动看不到效果。

## 二、参考与取舍

| 模式 | 来源 | 采用方式 |
| --- | --- | --- |
| 搜索放在首页最上方、最显眼 | 1Password 8（2025 起搜索栏移回顶部）、Bitwarden 新版原生 App | 卡包首页第一个控件就是 52dp 白色胶囊搜索框 |
| 收藏 / 置顶只给少数几张整卡面，其余用紧凑行 | Apple 钱包、Google 钱包、1Password 首页收藏 | 置顶改为横向的小卡面（216dp 宽），下面是分组列表 |
| 快速筛选标签：全部 / 置顶 / 两步验证 / 类型 / 标签 | Aegis 3.3 起把分组改成主界面上的筛选标签；Bitwarden 的类型筛选 | 新增“两步验证”筛选，选中后行尾直接显示实时验证码，点一下复制（Aegis 的验证码列表） |
| 详情页顶部的大号复制按钮 | 1Password、Proton Pass 详情页（点字段即复制） | 卡面下方加 1–2 个品牌浅底大按钮（账号 / 密码、持卡人 / 卡号……），整行点按复制保留 |
| 列表行左右滑动 | Cashew（滑动选择 / 编辑）、iOS 邮件式滑动操作 | 卡包：右滑置顶、左滑复制账号；账本：右滑“再记一笔”、左滑删除（先确认）；读屏有同名自定义操作 |
| 长按出操作菜单 | Aegis、Cashew | 卡包长按沿用快速复制面板；账本长按：修改 / 再记一笔 / 删除 |
| 底部栏中央“＋” | 钱迹首页中央“＋”、小星记账 | 底部栏改为“卡包 · ＋ · 账本”，＋ 跟随当前分区（新建卡片 / 记一笔），去掉悬浮按钮 |
| 一屏记账：分类宫格 + 计算器键盘 + 再记 | 钱迹（默认选中第一个分类、再记一笔）、iCost、鲨鱼记账“3 秒记账” | 记一笔面板重排：金额在最上、5 列圆形分类宫格、一行账户 / 日期 / 时间、备注与标签、无描边键盘 |
| 默认账户跟分类走 | 钱迹 FAQ：“某一分类上次使用的账户” | `EntryDefaults.accountFor`：选了分类就换成这个分类上次用的账户；手动改过账户后不再自动换 |
| 首页常用分类一点即记 | iCost / 钱迹的模板与快捷记账、Ivy Wallet 首页快速添加 | 账本首页“快速记一笔”：最近 60 天最常用的 6 个支出分类，点一下带着分类打开面板 |
| 日历月视图 | 一木记账、小星记账（结余热力图）、Money Manager 的 Calendar 标签 | 账本“明细 / 日历”切换；日历每格显示当日支出简写，支出越多底色越深，点日期列出当天流水 |
| 稳定的一个品牌色 + 中性灰阶 | Bitwarden / Proton 的单一品牌色；Material 3 | 只保留一个靛青主色；可选 Material You 动态取色（默认关闭） |

**没有采用**：自动记账（需要无障碍 / 通知权限，违背“不加权限”）；相机扫码（要相机权限）；Bitwarden 2024.12 浏览器扩展那种“点复制先出菜单”的两步复制（社区反馈复制要多点一次，正是要避免的）。

## 三、新的设计系统

### 颜色（一个品牌色）
| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| primary / accent | `#3E4FC1` 靛青 | `#9AA6FF` | 主按钮、选中、置顶、底栏“＋”、今天 |
| accentSoft | `#E8EAFA` | `#22274A` | 选中标签底、次要按钮、快捷复制按钮 |
| bg | `#F5F6F8` | `#0E1014` | 页面底 |
| surface | `#FFFFFF` | `#171A20` | 分组容器、搜索框、底栏 |
| surfaceAlt | `#EDEFF3` | `#20242C` | 未选中标签、键盘、输入胶囊 |
| border | `#E2E5EA` | `#2A2F38` | 只用于输入框与分隔线 |
| 文字三级 | `#15171C / #4B515C / #646C7B` | `#ECEEF2 / #B3B9C4 / #8A93A1` | 三级文字在 bg、surface、surfaceAlt 上对比度均 ≥ 4.5:1 |
| 支出 / 收入 / 转账 | `#C4532D / #1E7A52 / #5B6577` | `#F59A7B / #6FD3A2 / #A9B3C4` | 只出现在账本 |

- 中性色改为冷灰，与卡面的冷色调一致；赤金只留在卡面芯片上。
- 图表第一色改为品牌靛青，其余低饱和色顺延。
- 动态取色：设置 → 外观 →“跟随壁纸取色”（Android 12+，默认关闭），只替换品牌色一组，背景与收支色不变。

### 文字
- 分区大标题“卡包 / 账本”：28sp Bold 黑体（`JkType.pageTitle`），宋体字标只留在锁屏 / 首次设置。
- 正文 15sp、辅助 13sp、说明 12sp；分组标题统一为 12sp 眉题 + “· 数量”，不再用数字小胶囊。
- 金额、卡号、验证码继续用等宽数字（tnum）。

### 形状与层次
- 分组容器 20dp 圆角、无描边无投影；列表行放进同一块分组（首尾圆角、中间 1dp 内缩分隔线）。
- 标签、按钮、搜索框、分段控件全部胶囊形；底部面板顶部 28dp 圆角。
- 层次只靠底色：bg → surface → surfaceAlt。

### 间距
- 4dp 网格；页面左右 20dp，分组内 16dp，标签间 8dp；行高 ≥ 64dp，触控区 ≥ 48dp。

### 图标
- 统一 Material Symbols Outlined（选中态用 Filled），20–22dp；分类图标放在圆形色底里。

### 导航与操作
- 底部栏：卡包 ·（56dp 品牌色“＋”）· 账本；“＋”跟随分区。悬浮按钮全部去掉。
- 卡包首页（列表默认，牌堆仍可切换）：大标题 → 搜索 → 筛选 → 体检 → 置顶小卡面 → 最近使用胶囊 → 全部（分组列表）。
- 账本首页：大标题 → 月份 +“明细 / 日历” → 月度汇总 → 快速记一笔 → 筛选 → 流水 / 日历。
- 关键任务步数（打开对应分区之后）：
  - 复制密码 / 卡号：搜索（可选）→ 点行尾复制，**1 次**；复制账号：左滑，**1 次**。
  - 看并复制验证码：点“两步验证”筛选 → 点验证码，**2 次**。
  - 记一笔：点“快速记一笔”的分类或底栏“＋” → 输金额 → 完成，**2 次点按 + 数字**。

## 四、1.0.0-beta 截图复查后的修正

逐张看过 CI 截图（浅色、深色、1.3 倍字号）后又改了这些：

- **置顶卡面**原来借用了“新建时选类型”的小卡面，只写着“银行卡”，认不出是哪一张；改为完整卡面（名称、打码卡号、有效期），宽度不变。
- **详情页大号复制按钮**：字段名较长或放大字号时，两个按钮改为上下两行，不再截断成“公民身份号…”。
- **账本首页（1.3 倍字号）**：“明细 / 日历”切换去掉图标、不折行；月度汇总的“日均支出”挪到第二行，三栏金额不再挤在一起。
- **深色分段控件**：选中段原来比轨道还暗、像凹下去，单独提亮一档（`segmentSelected`）。
- **不可用的主按钮**：从一大块深灰改为浅灰底 + 三级文字，冷却中的锁屏更安静。
- **预算进度条**：正常时用品牌靛青（原来是绿色），快用完用支出橙，超支用红色；不再拿靛青当“警告”。
- **数字键盘**：没有“再记”时（修改已有流水），“完成”占两格，不留空洞。
- **设置页**抽出无状态的 `SettingsContent`，补上设置 / 加密备份的截图测试（浅 / 深 / 1.3 倍字号）。

## 五、界面测试随机卡住的原因

Robolectric 界面测试一起跑时随机在 `waitForIdle()` 报 `AppNotIdleException`，单独跑都过。原因不在页面里的计时器：
Compose 的主线程调度器 `AndroidUiDispatcher.Main` 是进程级单例，排队时先把“已安排派发”标志置为 true，再往主线程投一条消息，等那条消息执行时才清零。
Robolectric 在两个测试之间会清空主线程消息队列；上一个测试结束时如果正好有这样一条消息没执行，标志位就永远停在 true，之后再也不派发，
全局快照的写入通知随之卡住（`hadSnapshotChanges=true`），下一个有动画或副作用写状态的页面就永远“不空闲”。
修法：`MainLooperDrainRule` 包在 Compose 规则外层，测试和 Compose 拆除结束后先把主线程消息跑空，再交给 Robolectric 重置；每个测试结束时也销毁自己开过的页面。
