# 金匮

只存在这台手机里的安全卡包：登录密码、银行卡、U 卡 / 硬件密钥、身份证、护照、社保卡、驾驶证、会员卡、门禁卡、Wi-Fi，以及任何你想自定义的卡片。

第一要务是安全，第二是顺手。

- 包名 `com.xiguli.jinkui`，minSdk 26，targetSdk 34
- 原生 Kotlin + Jetpack Compose（Material 3），ViewModel + Repository 分层，手动依赖注入
- 不申请任何联网权限

## 当前状态

`0.2.0`。

- `0.1.0` 已在 GitHub Actions 上构建通过并产出 Debug APK。
- `0.2.0` 的改动在提交前只跑过单元测试（56 个，全部通过）和一次类型检查，**没有经过 Gradle 构建，也没有上过真机**。新的卡面纹理是用 Canvas 画的，提交时没有看过实际渲染效果，以 CI 结果和真机观感为准。

## 功能

- **首次启动**：设置主密码（带强度提示），随后可选开启生物识别与 PIN。
- **解锁**：主密码始终可用；生物识别；6–12 位 PIN（自绘数字键盘，不经过系统输入法）。
- **主页**：搜索（名称 / 标签 / 备注）、按类型或标签筛选、置顶卡面、最近使用、全部列表；长按卡片直接复制账号或密码。
- **卡片**：11 种类型预设；名称、标签、卡面、自定义字段（文本 / 密码 / 数字 / 日期 / 网址，可标记为敏感）、备注、证件照片附件；可以把一张卡片复制一份当模板。
- **卡面**：每种类型有自己的配色、纹理和标志物（见下表），也可以在编辑页改用纯色。
- **详情**：敏感字段默认打码，点眼睛才显示；点整行即复制；长数字四位一组显示。
- **密码生成器**：长度 6–64，可选大小写、数字、符号，可避开易混字符；可直接填回正在编辑的字段。
- **历史密码**：敏感字段被修改时保留旧值（可在设置里关闭）。
- **设置**：自动锁定时间、剪贴板清空时间、浅色 / 深色 / 跟随系统、加密备份导出与导入、修改主密码、输错自毁开关、立即清空全部数据。

## 安全设计

### 密钥层级

```
主密码 ──PBKDF2-HMAC-SHA256（60 万次）──▶ 口令密钥
                                            │ AES-256-GCM
                                            ▼
                                       [口令信封] ──Keystore 主密钥 AES-256-GCM──▶ 落盘
                                            │
                                    保险库密钥 VK（随机 256 位，只在解锁期间存在于内存）
                                            │ HKDF-SHA256
                    ┌───────────────────────┼───────────────────────┐
              SQLCipher 库密钥           字段密钥                 附件密钥
```

- **Keystore 主密钥**：AES-256-GCM，不可导出，设备支持时放在 StrongBox。它不直接加密每个字段，而是包裹“口令信封”——每次读写字段和附件都走 Keystore 太慢，所以采用信封加密。
- 解开保险库需要同时具备**这台设备的 Keystore** 和**正确的主密码**。本机不保存任何口令哈希，口令是否正确由 GCM 认证标签判定。
- **生物识别**：另一把必须经强生物识别认证才能使用的 Keystore 密钥，用来封装 VK；系统里新增指纹或面容后自动失效，需用主密码重新开启。
- **PIN**：可选的应用内 PIN，同样是“PBKDF2 + Keystore”两层封装。它是便捷方式，强度低于主密码。

### 数据

- 数据库：SQLCipher 整库加密。
- 字段值、备注、历史密码、附件：入库 / 落盘前再做一层 AES-256-GCM，每段密文都绑定到所属的卡片与字段（AAD），挪到别处无法解密。
- 名称与标签只有 SQLCipher 这一层保护。
- 解锁后，卡片解密到内存供搜索与展示；锁定时清零密钥、关闭数据库、销毁界面里的明文。

### 其他防护

| 项目 | 做法 |
| --- | --- |
| 离线 | Manifest 不声明 `INTERNET`，并显式移除依赖库可能带入的联网权限；CI 会检查 APK 的权限列表 |
| 自动锁定 | 切到后台后按设定时间锁定（立即 / 30 秒 / 1 分钟 / 5 分钟 / 10 分钟）；前台无操作同样锁定（最短 30 秒） |
| 防截屏 | 主窗口与所有对话框都带 `FLAG_SECURE`；最近任务列表不显示内容 |
| 剪贴板 | 复制的内容标记为敏感，默认 30 秒后清空 |
| 输错自毁 | 默认开启：主密码或 PIN 连续输错 10 次，清空数据库、附件与全部密钥；第 3 次起有递增的冷却时间 |
| 备份 | 只导出用主密码加密的 `.jkbak` 文件（PBKDF2 + AES-256-GCM），没有任何明文导出；导入时先做完整性校验，再按更新时间合并 |
| 系统备份 | 关闭系统云备份与换机迁移 |

### 已知的边界

- 字符串在 JVM 堆里无法可靠清零：解锁期间，已解密的卡片内容存在于进程内存中。
- 剪贴板清空靠进程内计时。如果进程在到点前被系统回收，要到下次启动时才补清。
- 修改主密码只更换口令信封，不会重新加密数据库；此前导出的备份仍用当时的主密码。
- 冷却时间按系统时钟计算，改系统时间可以跳过冷却，但跳不过 10 次的自毁上限。
- 已 root 或已被攻破的设备不在防护范围内。

## 界面

- 统一 8dp 间距节奏；标题亮 / 正文适中 / 辅助灰三级文字。
- 用 1dp 极淡描边区分层次，不用投影；卡片与面板 24dp 圆角。
- 浅色暖纸白、深色暖墨黑；赤金只做点缀（品牌、置顶、选中）。
- 置顶卡片、详情页顶部、编辑页预览、新建时的类型选择用同一个“卡面”组件；列表行直接落在底色上，只留分隔线。
- 卡面的版式、圆角、描边和字体全部一致，区别只在配色、纹理与标志物：

| 类型 | 底色 | 纹理与标志物 |
| --- | --- | --- |
| 登录密码 | 靛青 | 渐隐的密码点阵 |
| 银行卡 | 玄黑描金 | 斜纹底 + 金色芯片 |
| U 卡 / 硬件密钥 | 钢青 | 电路走线 + 触摸环 |
| 身份证 | 证件蓝 | 防伪同心纹 + 人像框 |
| 护照 | 绛红烫金 | 经纬地球 |
| 社保卡 | 松绿 | 十字纹 |
| 驾驶证 | 沥青灰 | 向远处收拢的车道线 |
| 会员卡 | 黛紫 | 斜向缎带 + 星芒 |
| 门禁卡 | 岩灰 | 感应波纹 |
| Wi-Fi | 湖蓝 | 信号弧 |
| 自定义 | 暖墨 | 简册竖纹 + 一道金色编绳 |

- 设计令牌在 `ui/theme/Theme.kt`，通用组件在 `ui/components/`，卡面在 `ui/components/CardFaces.kt`。

## 构建

需要 JDK 17 与 Android SDK（compileSdk 34）。

```bash
./gradlew testDebugUnitTest   # 单元测试
./gradlew assembleDebug       # Debug APK：app/build/outputs/apk/debug/
```

Release 构建已开启 R8，需自行配置签名。

## 目录

```
app/src/main/java/com/xiguli/jinkui/
├── core/crypto/      纯 Kotlin 的加密工具：AES-GCM、PBKDF2 / HKDF、字段加密、口令信封、备份文件格式、密码生成器
├── core/security/    Keystore、保险库解锁与清空、自动锁定、剪贴板、生物识别
├── data/model/       卡片模型与类型模板
├── data/db/          SQLCipher 数据库与附件文件
├── data/backup/      备份内容的 JSON 结构
├── data/repo/        卡片仓库、设置、备份导入导出、图片导入
└── ui/               主题、组件、导航与各页面（setup / lock / home / card / generator / settings）
app/src/test/         加密工具类、备份编解码与数据模型的单元测试
```
